# Family Manager — Roadmap (updated 15 Oct 2026)

## Context
"Family Manager" is a free, installable PWA with independent tabs (mini-apps) for a family's money, documents, places, study and more. Admin-controlled access, offline use, voice input and AI help (quiz creation first). Built for non-technical users, used mainly **on a phone, one-handed**: compact, icon-led, colourful. Text size is a setting (Small by default, Normal, Large). Guided mode and reminders later. Android phones + Windows laptops, English only. 20+ users scaling to hundreds, multi-family (owner approves each family; owner is super-admin).

This file is the hand-off document. It contains no secrets; keys go only in `.env.local`, which is git-ignored.

## Focus (owner instruction, 10 Oct 2026)
**Only the Expenses app until it is finished.** Documents, Locations, Study, Passwords, Medical, Work to do and the admin screens wait. Only Expenses-related fixes and the items below are in scope.

## Final decisions
- Stack: React + Vite + TypeScript PWA, Supabase (free tier only, no paid plan). Login = **name + password** (decided 15 Oct; Google sign-in dropped). Each person has a unique login name (their name in lower case with dots, e.g. `zawed.khan`). Typing an email still works at sign-in. New people sign up with just a name and password; behind the scenes they get a placeholder address `<login name>@example.com` that is never emailed. PIN and fingerprint unlock later.
- Roles: admin (full) / adult / teen / child / guest. Everyone but admin starts with no access to any tab; admin grants none / view / edit / full per tab per person. Admin sees everything; private items visible only to owner and admin. Activity log is admin-only.
- Families start "pending"; super-admin approves.
- Currencies SAR + INR with automatic conversion. Expenses by typing, voice or receipt photo.
- Passwords tab: master PIN, never sent to AI, admin can reset the PIN (old passwords are lost).
- Study (daughter, 12, class 5 CBSE, Maths and Science): quizzes (multiple choice + written), results go to admin first then published to her, she uses her laptop, feedback and roadmap from history. School portal site is only a marketing page, so use uploaded PDFs and forwarded email, not login automation.
- **Expenses mobile redesign (decided 10 Oct):**
  - Mobile-first: single column, bottom bar **Home / Add / Reports / Settings** (Add is the raised centre button), buttons within thumb reach.
  - **Day / Week / Month** switch at the top of Home and Reports, with ‹ › to move between periods. Weeks run Sunday to Saturday.
  - **Text size** setting Small / Normal / Large, Small by default. Symbols (icons/emoji) preferred over words; short labels only where an icon alone is unclear.
  - **Add flow like Monefy:** number pad, tap a category icon, tap the green ✔. SAR/INR toggle on the pad.
  - **Own categories and sub-categories**, created from the Add screen or Settings; a starter set is pre-filled (Food, Groceries, Transport, Bills, Home, School, Health, Shopping, Fun, Other, each with a few sub-categories). Sub-category is optional. One level of sub-categories only.
  - **Exchange rate** entered once in Settings (1 SAR = x ₹); it is stored on each phone, not per expense.
  - Modelled on Monefy (fast add), Money Manager (category/sub-category, day/week/month), Spendee/Wallet (ring chart, budgets) and Splitwise (who spent).
  - All extras wanted: search/filter, edit, budgets per category, repeating expenses, CSV export, receipt photo, voice. **Receipt photo first, voice after.**
  - Look stays as is (purple/orange); may change later. No dark mode for now.
- Medical tab: end of 3rd week of October.
- Emergency access for wife after 1 week of admin inactivity: later phase.
- Free-tier handling (recommended, owner to confirm): keep-alive ping against pausing, large PDFs via links (Google Drive), scheduled data export + "Download my data" button.

## Owner steps
1. Create a free Supabase project; copy Project URL and anon (public) key. Never share the `service_role` key or DB password.
2. Run `supabase/migrations/0001_core.sql` in the Supabase SQL Editor.
3. Authentication > Email: switch off "Confirm email" (free built-in email is likely rate-limited; verify in docs).
2b. Then run `supabase/migrations/0002_expenses_mobile.sql`, `0003_receipts_storage.sql` and `0004_login_by_name.sql` the same way, in that order (run 0004 **before** the app update that uses it goes live). If 0003 complains about the bucket, create a **private** bucket named `receipts` in Storage and re-run the policy part.
4. Put the URL and key in `.env.local` (see `.env.example`); never commit it.
5. Create the owner account in the app, then make it super-admin with one SQL line: `update public.profiles set is_super_admin = true where email = '<owner email>';`
6. Confirm the three free-tier choices (keep-alive, large PDFs via links, backups).

## Open items
- Anyone who knows an exact login name can learn the email behind it (needed so a name can be turned into a sign-in). For name-only accounts that email is just the placeholder.
- Name-only accounts have no real email, so **there is no "forgot password" by email**; the admin has to help (reset in Supabase). Free-tier built-in email is rate-limited anyway. Revisit if real emails are wanted.
- "Confirm email" must stay **off** in Supabase (owner step 3), or name-only sign-ups cannot get in.
- Owner to try the Expenses redesign on the phone and send feedback; more screens/changes follow from that.
- Repeating expenses are created when the person who made them opens the app (no server job on the free tier), so a missed day appears the next time they open it.
- Private expenses: the receipt photo is protected by the unguessable file name and the hidden expense row, not by a separate rule.
- Categories can only be created while online (the list is cached for offline adding).
- Confirm free-tier choices above.
- Verify Supabase free limits on supabase.com/pricing (about 500 MB DB, 1 GB storage, pauses after about 1 week idle, no automatic backups; figures from a search, not confirmed).
- Deadline of 12 Oct is a starter version only (login + Expenses).
